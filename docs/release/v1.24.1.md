# v1.24.1

> 릴리스 날짜: 2026-10-17

`harness-devkit` 2.0.0 의 문서를 정리한 패치 릴리스다. 동작 변경은 없다.

---

## 🔄 Changed

- **`docs/guide/harness-devkit.md` 2절 도식** — 서브에이전트 9개를 이름·모델·산출 파일이 보이는 개별 노드로 다시 그리고, 엣지에 전달 파일과 분기 라벨(`REVISE ≤2라운드`, `FAIL ≤2`, `3번째 FAIL: blocked`)을 달았다
- **`plugins/harness-devkit/README.md`** — 서브에이전트 관계도·단계 흐름도·기능 릴레이 시퀀스 다이어그램과 에이전트별 읽기/쓰기 표를 추가했다
- 루트 `README.md` 의 `harness-devkit` 설명에 서브에이전트 수를 반영하고, 선행 요건(`grill-with-docs`, Playwright MCP)을 보완했다
- `AGENTS.md` 의 구조 도식에 `agents/<agent>.md` 를 추가했다
- 훅 `_feature_list_rules.py`·`harness_feature_list_gate.py` 의 주석에서 1.x 의 "스프린트" 용어를 "기능" 단위로 고쳤다 (코드 동작 동일)

## ✨ Added

- **`docs/guide/harness-devkit-flow.html`** — 흐름도의 인터랙티브 버전. 노드에 마우스를 올리면 읽고 쓰는 파일이, 노드를 누르면 연결된 흐름만 강조된다. 저장소를 클론해 브라우저로 연다 (GitHub 에서는 렌더되지 않는다)

## 🧹 Chore

- `.playwright-mcp/` 를 `.gitignore` 에 추가했다
