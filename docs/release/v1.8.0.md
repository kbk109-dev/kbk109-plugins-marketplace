# v1.8.0

> 릴리스 날짜: 2026-08-20

**배포되는 플러그인은 하나도 바뀌지 않았다.** 이번 릴리스는 저장소 자신의 정비다 —
v1.7.0 이 만든 `refresh-agent-rules` 를 이 저장소에 직접 돌려, 그 릴리스 노트에 알려진
이슈로 적어 둔 *"이 저장소 자신의 `AGENTS.md` 가 255줄"* 을 해결했다. 자기 규칙을 자기가
어기고 있는 상태를 그대로 두면, 그 규칙을 배포하는 플러그인의 근거가 사라진다.

정리 과정에서 두 번째 문제가 드러났다. `AGENTS.md` 는 **모든 대화의 머리에 붙는다.**
"새 플러그인·스킬 만들기" 48줄은 플러그인을 만들 때만 필요한 절차인데, 오타 한 줄 고치는
대화도 그 48줄의 토큰을 내고 있었다.

---

## ✨ Added

- **`.claude/skills/new-plugin` 스킬** — 새 플러그인 생성(A) / 기존 플러그인에 스킬 추가(B)
  절차를 조건부 로드 스킬로 분리했다. **상시 비용이 0 이다.** A/B 로 나눈 이유는
  `marketplace.json` 등록 여부와 버전 규칙이 두 경우에 다르기 때문이다 — 하나로 묶으면
  B 케이스에서 틀린 단계를 따라간다.
  - 옮긴 것은 **순서뿐이다.** 제약(두 불변식 · 버전 위치 · 넣지 않는 것)은 `AGENTS.md` 에
    남기고 스킬 본문이 역참조한다. 제약은 모든 대화에서 지켜야 하지만 절차는 그렇지 않다.
  - 플러그인 스킬이 아니라 **프로젝트 스킬**이므로 bare 이름으로 호출된다.
    `validate-marketplace.sh` 는 `plugins/` 만 훑으므로 네임스페이스 검사(검사 5) 대상 밖이다.
- **`.claude/agent-rules.state.json`** — 다음 `refresh-agent-rules` 의 기준점. **커밋 대상**이다.
  팀원이 각자 다른 기준점을 들면 같은 변경을 몇 번이고 다시 제안하게 된다.

  이 저장소는 `project-conventions` 의 첫 사용처다. 카파시 4원칙 항목은 0/8 이었다.
  - **카파시 4원칙 블록을 H1 *아래*에 넣었다** (+12). `retitle` 이 첫 비어있지 않은 줄만

  - "새 플러그인·스킬 만들기" 48줄 → 프로젝트 스킬 포인터 (−46)
  - 산문·이력 서술 축약 (−22) — 이관 시 수치, 훅 경계 탐색 근거(플러그인 README 에 있다),
    `CLAUDE.md` 포인터 재설명 등
  - **마커 블록(191–199)은 손대지 않았다.** `init-agent-rules` 소관이고, 재실행하면 덮어쓴다.
- **루트 `README.md` 의 사실 불일치 2건을 고쳤다.**
  - 플러그인 제작 절차 위치가 `AGENTS.md` 를 가리키고 있었다 → `new-plugin` 스킬로 정정.
    이번 릴리스가 만든 불일치다.
  - *"LLM의 4가지 구조적 실패 모드"* → **5가지**. `AGENTS.md` 표는 다섯 번째로
    **훈련 컷오프 밖 할루시네이션**(grounding 게이트)을 포함하는데 README 만 원문의 4가지를
    인용하고 있었다. 이 저장소의 SSoT 는 `AGENTS.md` 다.

## 기술 상세

### 유실 검증

축약은 되돌리기 어려운 편집이다. 코드조각 99개를 토큰 단위로 대조해 유실 5개를 확인했고,
정보 손실인 2개(`verify_tech_tokens.py`, `@AGENTS.md`)는 **줄을 안 늘리고** 되살렸다.
나머지 3개는 의도된 이동이다. 명령 · 표 · 코드블록 · 두 불변식 · 한글 `\b` 경계 함정은
전부 남겼다 — 이것들은 없으면 조용히 깨지는 종류다.

마켓플레이스 `metadata.version` 만 1.7.0 → **1.8.0**. 스킬 18개 · 플러그인 6개 유지.

`AGENTS.md` 는 *"문서만 고치는 변경은 버전을 올리지 않는다"* 고 정한다. 이번 변경은 그 규칙대로면
버전 대상이 아니지만, **태그를 찍어 이 저장소 정비 시점을 표시**하기 위해 마켓플레이스 버전만
올렸다. 설치된 플러그인의 동작은 v1.7.0 과 동일하다 — 업데이트해도 바뀌는 것이 없다.

이 저장소는 `package.json` / `app.json` 이 없는 플러그인 마켓플레이스라 Expo 빌드 번호는 해당 없음.
