## 🔄 Changed

- **에이전트 작업 기점을 `dev` 로 전환** — `git-branch-workflow` 규칙이 `main` 에서 분기·머지하던
  것을 `dev` 경유로 바꿨다. 작업 브랜치는 `dev` 로만 머지하고, `main` 체크아웃 후의 머지·태그·푸시는
  에이전트가 하지 않는다. 예외는 사용자가 릴리스 스킬을 직접 호출한 경우뿐이다.
- **3절 "이미 다른 브랜치에 있을 때"** — `dev` 도 `main` 도 아니면 에이전트가 이어서 할지 `dev` 로
  머지하고 새 브랜치를 팔지 스스로 정한다. 미커밋 변경의 커밋 승인을 못 받았으면 브랜치를 옮기지 않는다.
